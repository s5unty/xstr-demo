## 手工回归（UI/交互）

| ID | 场景 | 步骤 | 预期 |
|---|---|---|---|
| UI-01 | 目标文本居中与留白 | 启动后观察主界面 | 目标区居中，左右有安全间距 |
| UI-02 | 光标跟随与不漂移 | 连续输入 `sy` / `syy` / `syym` | 光标跟随推进，目标字不左右漂移 |
| UI-03 | 码表/候选锚定光标 | 输入任意编码 | 气泡出现在光标附近，左侧对齐 |
| UI-04 | 空输入隐藏候选 | 清空 `raw` | 候选气泡隐藏 |
| UI-05 | 光标动画 | 观察静止与移动 | 静止闪烁，移动有过渡与尾焰 |
| UI-06 | 头顶编码显示规则 | 观察普通字/一简字/标点 | 普通字最多2码；一简字1码；标点不显示编码 |
| UI-07 | 候选垂直展示 + 翻页键 | 输入多候选编码后按 `-`/`0` | 候选纵向4行，`-`下翻、`0`上翻 |
| UI-08 | 自定义目标粘贴 | 右下粘贴文本后点“应用目标” | 目标立即切换并提示成功 |
| UI-09 | 键位图与目标区防遮挡 | 启动后确认 `cqkm.png` 可见，再粘贴超长目标文本 | 键位图始终可见；目标区有长度上限且不出现滚动条，不与键位图重叠 |
| UI-10 | 键位图原图规格显示 | 启动后观察 `cqkm.png` | 桌面端按原图尺寸 `1078x412` 显示，不被压缩变小 |
| UI-11 | 键位图居中且不被遮挡 | 启动后观察 `cqkm.png` 的位置，再粘贴大段目标文本并输入 | 键位图保持居中可见；目标区位于图片下方独立区域，不覆盖图片 |
| UI-12 | 单行主输入区与上下文分层 | 粘贴超长目标，连续输入推进光标 | 目标区仅中间 1 行显示“当前输入行”；上方显示已输入上下文，下方显示待输入上下文，视觉明显区分 |
| UI-13 | 上下文省略号提示 | 粘贴超长目标并输入到中段 | 若上方/下方仍有更多文本，对应方向显示 `…`，且目标区无滚动条 |
| UI-14 | 编码显示分层规则 | 连续输入并观察三层文本 | 中间主输入行不显示头顶编码；上/下文行显示头顶编码；三层文本宽度一致 |
| UI-15 | 光标边界与开局空白 | 打开页面观察后按 Enter 开始 | Enter 前目标区为空且光标不越界；Enter 后第一行文本进入目标区并可输入 |
| UI-16 | 上下文与主行同宽感知 | 连续输入并对比三层文本 | 上/下文字符字号与主行一致，不再出现明显“上下更窄”观感 |
| UI-17 | 开局下方待输入预览 | 进入菜单态（未按 Enter）观察目标区 | 中间主输入行为空，但下方显示“即将输入”的首行文本；若后续还有内容显示 `…` |
| UI-18 | 光标在主输入框内 | 开始游戏后连续输入并观察光标 | 光标始终位于中间主输入框内部，不再落到框体下方 |
| UI-19 | 输入模式提示与主行垂直居中 | 观察默认模式后按 `Shift` 来回切换，再输入 | 页面显示“输入模式：中文/英文（Shift切换）”；主输入行文本与光标位于输入框垂直中部 |
| UI-20 | 上下文区与背景融合 | 开始游戏后观察上下文显示区域 | 上下文在主输入框外显示；外层区域透明、无边框、无底色，与背景融合 |
| UI-21 | 主输入行右侧防越界 | 连续输入使当前行接近满行 | 当前输入文本不超出主输入框右边界；必要时自动减少单行显示字符并在框内裁剪 |
