# 输入 UI 说明

- UI 实现方式：DOM Overlay（不嵌入 Three.js）。
- 键位图实现：Three.js 场景内 3D 键帽（混合方案），DOM 不再承载 2D 键帽按钮。
- 区域：
  - 目标文本行：已输入绿色、待输入灰色、当前位置光标。
  - 码表行：显示当前字母缓冲。
  - 候选行：显示 `1~4` 候选编号。
  - 状态行：操作提示与流程提示。
  - 指标行：CPM/正确率/连击。
- 焦点：点击画布后仍以窗口键盘输入为主。
- 3D 键盘鼠标交互：
  - 左键点击键帽：触发真实输入（进入 IME/游戏流程）。
  - 右键拖拽：旋转视角。
  - 中键拖拽：平移视角。
  - 滚轮：缩放视角。
