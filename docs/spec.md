# 中文打字游戏 MVP 规格

## 玩法闭环
- 流程：`开始(menu) -> 练习(playing) -> 结算(result)`。
- 目标：按顺序输入目标中文文本，比较 `confirmedText` 与 `targetText`。
- 计分：统计 CPM、正确率、连击、最高连击。

## 输入法交互约定（内置 Web IME）
- 码表键 `a-z` 与 `;`：写入码表缓冲 `raw`。
- 常见标点键（按 `xstr/symbols.yaml` 的 `half_shape` 映射）可直接上屏中文标点；
  例如：`,` -> `，`，`.` -> `。`，`<` -> `；`，`>` -> `！`，`?` -> `？`。
- 大写补码：在连续输入场景中可输入 `A-Z` 作为补码（例如 `hrG`）以提升末段命中精度。
- `Backspace`：优先删除 `raw`；`raw` 为空时删除已上屏文本最后一字。
- `Esc`：清空 `raw`。
- `1~4`：选择当前候选栏对应项并上屏。
- `Space`：选择第 1 候选并上屏。
- `Enter`：`menu/result` 状态用于开始新局；`playing` 中可作为第 1 候选上屏。
- `-` 下翻、`0` 上翻（同时保留 `ArrowLeft/ArrowRight` 翻页）。
- 连续输入识别：允许连续输入多个字的短码并组合成词语序列（例如 `nhhbsmjd -> 你好世界`）。
- 前缀潜在候选：当 `raw` 是某候选完整码前缀时，候选栏可显示潜在项，并以 `(~待补码)` 标注（例如 `xlh -> 需(~d)`）。
- 一简字连续输入：支持以 `;` 或 `z` 结尾的一简字码作为连续片段（例如 `...d;` / `...dz` 用于「的」）。

## UI 文案
- 状态提示：
  - menu: `按 Enter 开始，输入字母或 ; 触发候选，空格上屏首选，1~4 直选，- 下翻，0 上翻，Esc 清空码表。`
  - result: `本轮完成，按 Enter 重新开始。`
- 指标文案：`CPM / 正确率 / 连击 / 最高连击`。
- 目标文字展示：居中显示在屏幕中部，左右保持安全留白，降低视线移动。
- 目标文字按“字单元”展示：每个字上方显示两码提示（小号字母），下方显示汉字。
- 候选预览高亮：当第 1 候选与当前位置后的目标文本完整匹配时，同时高亮目标中的对应片段与候选第 1 项。
- 光标跟随预览进度：未提交时，光标可移动到当前第 1 候选可匹配的位置。
- 码表与候选气泡：显示在目标区光标附近，不固定在页面底部。
- 码表显示切分：按当前匹配字的编码切分显示（例如 `rhly -> rh ly`）。
- 候选栏垂直显示：一行一个候选，默认每页 4 项。
- 提交结果着色：提交后按逐字对齐结果显示，匹配字符为绿色，不匹配字符为红色。
- 自定义目标：支持在界面右下角粘贴文本并一键应用为当前练习目标。

## 验收标准
- 可在 Chromium 桌面浏览器运行。
- 不依赖系统输入法与 composition 事件。
- 形成完整闭环：`码表 -> 候选 -> 上屏 -> 对齐 -> 计分 -> Three.js 反馈`。
- 候选可通过 `1~4` 和空格上屏。
- 错字可被标记并影响正确率/连击。
